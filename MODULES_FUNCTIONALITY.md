# Aevura OS - Module Functionality & Technical Workings

Aevura OS operates as a collection of specialized "Modules", each designed to solve a specific professional problem using AI.

## How the System Works (Global)
1. **Authentication:** When a user visits a module, `os-ui.js` immediately pings the `/api/me` endpoint. If no valid session exists, the user is ejected to `signin.html`.
2. **Global HUD:** Pressing `Ctrl+K` triggers `command-palette.js`, which opens a fast-action search overlay. This allows power users to navigate between modules without touching a mouse.
3. **AI Pipeline:** Modules collect user input via standard HTML forms, compile the data into a structured prompt, and POST it to the backend (`server.ts`). The backend securely forwards the prompt to the **Gemini API**, processes the Markdown response, and sends it back to the frontend to be rendered in the UI.

## Module Breakdown

### MOD-00: Core Engine Laboratory (`index.html`)
*   **Functionality:** Analyzes the user's overarching goals to generate a multi-tier roadmap.
*   **Technical:** It interacts with `/api/generate-roadmap`. It establishes the baseline data that the `Progress Tracker` relies on.

### MOD-01: Freelancer Assistant (`freelancer-assistant.html`)
*   **Functionality:** Generates highly persuasive, data-backed client proposals and calculates optimal pricing structures.
*   **Technical:** Passes client pain points and project scope to the AI engine to return a structured markdown proposal.

### MOD-02: Real-World Simulation (`simulation.html`)
*   **Functionality:** An interactive chat interface where users practice high-stakes conversations against AI personas (e.g., "The Scope Creeper", "The Late Payer").
*   **Technical:** Utilizes a custom conversation loop. Users can also define custom scenarios, which are saved to their profile in the database via `/api/sim/custom-save`. When a session ends, the AI evaluates the transcript and returns a score out of 10 with actionable critique.

### MOD-03: Case Study Architect (`case-study-architect.html`)
*   **Functionality:** Transforms raw project notes and code snippets into polished portfolio case studies.
*   **Technical:** Features a dual-pane UI where raw input on the left yields a rendered, professional Markdown document on the right.

### MOD-04: Skill Gap Analyzer (`skill-gap-analyzer.html`)
*   **Functionality:** Compares the user's current technical stack against live job descriptions to find weaknesses.
*   **Technical:** Uses AI to perform a semantic diff between the user's profile data and the target job, highlighting missing keywords and suggesting learning paths.

### MOD-05: Contract Shield (`contract-generator.html`)
*   **Functionality:** Generates iron-clad freelance agreements.
*   **Technical:** Focuses heavily on edge-case protection (late fees, scope creep parameters) to output a legally structured document.

### MOD-07: Decision Engine (`decision-engine.html`)
*   **Functionality:** Helps eliminate choice paralysis by evaluating branching career or technical paths.
*   **Technical:** Users input a crossroads (e.g., "Learn React vs Vue"). The engine mathematically weighs the options based on the user's profile and delivers a brutally objective recommendation.

### MOD-08: Progress Tracker (`progress.html`)
*   **Functionality:** Monitors roadmap completion and provides strategic insights.
*   **Technical:** Hooks into the data generated by MOD-00. The frontend caches this data (`sessionStorage`) to ensure instant load times across page navigations.
